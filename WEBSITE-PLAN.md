# Website-Konzept: Martin's Reithof

> Basis: 6 vorhandene Info-Flyer (Öffnungszeiten, Preisliste, Ponyreiten/Angebote,
> Pferde mieten, Ponyclub, Herbst-Reitlager). Stand: September 2026.

---

## 1. Zielsetzung & Zielgruppen

**Ziele der Website**
- Zentrale Anlaufstelle: Alle Infos aus den Flyern digital, immer aktuell
- Mehr Anmeldungen (Ponyclub, Reitlager, Geburtstage) & Anrufe
- Lokale Sichtbarkeit (Google-Suche «Reithof Zürich-Rümlang / Zürich Unterland»)

**Zielgruppen (nach Priorität)**
1. Eltern mit Kindern (5–12 J.) → Ponyreiten, Ponyclub, Reitlager, Geburtstage
2. Anfänger & Gelegenheitsreiter → Spazierreiten, Ausritte
3. Fortgeschrittene Reiter → Pferdemiete («quasi eigenes Pferd»)
4. Schulklassen/Firmen/Gruppen → besondere Anlässe (potenzial, in Flyern nur angedeutet)

**Tonalität:** Herzlich, familiär, bodenständig – aber modern & aufgeräumt.
Leitsatz aus Flyer: *«Bei uns ist jeder herzlich willkommen!»* und die Werte
**Fairness · Respekt · Leidenschaft**.

## 5. Technische Umsetzung (Empfehlung)

| Baustein | Empfehlung | Begründung |
|---|---|---|
| Framework | **Astro** (statisch) oder Next.js | schnell, SEO-stark, günstig hostbar |
| Styling | **Tailwind CSS** | schnelles, konsistentes CD-Setup |
| Hosting | Netlify / Vercel / Cloudflare Pages | kostenlos bis günstig, HTTPS inkl. |
| Domain | **martins-reithof.ch** (existiert lt. E-Mail) | Weiterleitung einrichten |
| Bilder | WebP/AVIF, responsive | Performance/Mobile |
| Formulare | Serverless (z. B. Netlify Forms/Formspree) | kein eigener Server nötig |
| CMS (optional, Phase 2) | Decap CMS / Keystatic | Aktuelles selbst pflegen |
| Analytics | Plausible/matomo (cookieless) | DSG-freundlich, kein Cookie-Banner |

**Performance-Ziele:** Lighthouse ≥ 90 (Mobile), LCP < 2,5 s.
